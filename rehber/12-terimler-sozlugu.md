# 12. Terimler sözlüğü

Rehberde geçen terimlerin kısa tanımları, alfabetik sırayla.

| Terim | Kısa tanım |
|---|---|
| **.env** | Secret'ların tutulduğu, Git'e eklenmeyen dosya |
| **.env.example** | `.env` içindeki değişkenlerin değersiz şablonu, Git'e eklenir |
| **.gitattributes** | Git'e dosyaları nasıl işleyeceğini (ör. satır sonu) söyleyen ayar dosyası |
| **.gitignore** | Git'in görmezden geleceği dosyaların listesi |
| **Ajan (agent)** | Verilen işi adım adım, araç kullanarak yürüten yapay zekâ |
| **API** | Programların birbiriyle konuşma kapısı |
| **API anahtarı** | Bir servisi senin adına kullanmayı sağlayan gizli kod |
| **Auto memory** | Claude'un bilgisayarında kendi tuttuğu notlar |
| **Auto mod** | Onayların çoğunu sormayıp işlemleri arka planda denetleyen izin modu |
| **Bağımlılık (dependency)** | Projenin ihtiyaç duyduğu dış paket |
| **Bağlam penceresi (context window)** | Claude'un o an dikkate alabildiği bilgi miktarı |
| **Betik (script)** | Otomatik çalışan küçük program |
| **Branch (dal)** | Ana hattan ayrı çalışma kolu |
| **CLAUDE.md** | Claude'un her oturumda okuduğu talimat dosyası |
| **CLI** | Komut satırı arayüzü, terminalden kullanılan program |
| **Clone** | Reponun kopyasını bilgisayara indirmek |
| **CMD** | Windows'un klasik komut penceresi |
| **Commit** | Projenin o anki halinin açıklamasıyla kaydı |
| **Conflict (çakışma)** | Aynı yerin iki farklı değişiklikle düzeltilmesi sonucu oluşan birleştirme sorunu |
| **Container** | Bir programı bilgisayarın geri kalanından ayrı çalıştıran yalıtılmış ortam |
| **CSS** | Web sayfasının görünüşünü belirleyen dil |
| **Dependabot** | Paketlerdeki bilinen açıklar için uyarı veren GitHub özelliği |
| **Deploy** | Projeyi canlıya almak, kullanıcıların erişimine açmak |
| **Diff** | İki sürüm arasındaki farkların listesi |
| **Fetch** | GitHub'daki yenilikleri öğrenmek, yerel dosyaları değiştirmeden |
| **Force push** | GitHub'daki geçmişin üzerine zorla yazmak |
| **Fork** | Başkasının reposunun kendi hesabındaki kopyası |
| **Git** | Değişiklik geçmişini tutan program |
| **GitHub** | Git repolarını internette barındıran hizmet |
| **GitHub CLI (`gh`)** | GitHub'ı terminalden kullanma aracı |
| **GitHub Pages** | GitHub'ın statik site yayınlama hizmeti |
| **Hosting** | Site dosyalarını internette barındıran hizmet |
| **HTML** | Web sayfasının iskeletini oluşturan dil |
| **İzin modu (permission mode)** | Claude'un neyi sormadan yapabileceğini belirleyen ayar |
| **Kütüphane** | Hazır kod paketi |
| **KVKK** | Türkiye'deki Kişisel Verilerin Korunması Kanunu |
| **Lint** | Kodu hata ve stil açısından otomatik tarama |
| **Lock dosyası** | Kurulu paket sürümlerini kaydeden dosya |
| **main** | Çoğu projede ana branch'in adı |
| **Manual mod** | Okuma dışındaki işlemler için onay isteyen izin modu |
| **Markdown** | `.md` uzantılı, basit işaretlerle biçimlendirilen metin |
| **Merge** | Bir branch'teki değişiklikleri başka bir branch'e işlemek |
| **Model** | Yapay zekânın kendisi, metin üreten sistem |
| **Noreply e-posta** | GitHub'ın commit'ler için verdiği gizli adres |
| **Paket yöneticisi** | Program veya kütüphane kurup güncelleyen araç (`pnpm`, `npm`, `pip`, `brew`, `winget`) |
| **PATH** | Bilgisayarın komutları aradığı klasör listesi |
| **Plan modu** | Claude'un plan önerdiği, onaya kadar kaynak dosya düzenlemediği izin modu |
| **PowerShell** | Windows'un komut penceresi |
| **PR (pull request)** | Değişiklikleri ana hatta alma talebi |
| **Private** | Yalnızca izinli kişilerin gördüğü repo |
| **Prompt** | Claude'a yazdığın istek |
| **Prompt injection** | Dosya veya sayfaya gizlenen metinle yapay zekâyı kandırma girişimi |
| **Public** | Herkesin görebildiği repo |
| **Pull** | GitHub'daki yenilikleri alıp yerel kopyaya işlemek |
| **Push** | Commit'leri GitHub'a göndermek |
| **Push protection** | Bilinen secret türlerini push sırasında engelleyen GitHub özelliği |
| **Remote** | Reponun uzak kopyası, adı genelde `origin` |
| **Repo (repository)** | Projenin dosyaları ve tüm geçmişi |
| **Revert** | Bir commit'i tersine çeviren yeni bir commit |
| **Revoke / rotate** | Anahtarı iptal etmek / yenisiyle değiştirmek |
| **Rewind** | Claude Code'da önceki bir noktaya dönme menüsü |
| **Ruleset** | GitHub'da branch koruma kuralları |
| **Sandbox** | Komutların erişimini sınırlayan yalıtılmış alan |
| **Sanal makine (VM)** | Bilgisayar içinde çalışan ayrı, yalıtılmış bilgisayar |
| **Secret** | Şifre, API anahtarı, token gibi gizli bilgi |
| **Sınıflandırıcı (classifier)** | Auto modda işlemleri denetleyen ayrı model |
| **Skill** | Claude Code'a eklenen, `/ad` ile çağrılabilen talimat paketi |
| **Slash komutu** | Oturum içinde `/` ile başlayan komut |
| **Statik site** | Sunucuda program çalıştırmadan, hazır dosyalardan oluşan site |
| **Subagent** | Claude'un iş devrettiği yardımcı ajan |
| **Terminal** | Yazıyla komut verilen pencere |
| **Test** | Kodun beklendiği gibi çalıştığını otomatik kontrol eden küçük program |
| **Token (erişim)** | Süreli erişim anahtarı |
| **Token (model)** | Modelin metni işlerken kullandığı küçük metin parçası, API faturası buna göre hesaplanır |
| **WSL** | Windows içinde Linux çalıştırma özelliği |
